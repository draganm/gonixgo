# gonixgo cgo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A program whose package graph contains cgo packages builds with the default `CGO_ENABLED`, one derivation per package, with libraries supplied through `packageOverrides`.

**Architecture:** `gonixgo resolve` stops rejecting cgo packages and prints a `cgo` attribute on their compile nodes. The Nix `compile` builder turns such a node into a `stdenv.mkDerivation` that runs the same `gonixgo compile`; the tool then performs cmd/go's cgo steps itself (cgo, the C compiles, the trial link, the Go compile, the pack). A binary that contains a cgo package links in a stdenv derivation with `-extld`. Pure packages and pure binaries keep their bare derivations.

**Tech Stack:** Go (standard library only), Nix 2.26+ with flakes, nixpkgs `nixos-26.05` (Go 1.26.7, clang 21 on darwin).

**Spec:** `docs/superpowers/specs/2026-10-05-cgo-design.md`. Read it first: the exact command lines of every build step are in its section "The build steps of a cgo package", and this plan refers to them as *spec step 1* to *spec step 5*.

## Global Constraints

- The tool uses only the Go standard library. `go.mod` has no `require` lines.
- Run Go commands through the flake's toolchain: inside the direnv shell, or `nix develop --command go …`.
- Any Nix command that evaluates a fixture needs `--option allow-unsafe-native-code-during-evaluation true`.
- `.#` flake references see only git-tracked files; the integration driver uses `path:` and sees untracked files too.
- Never leave built binaries in the tree: no `go build` output inside the repository, always `--no-link` with `nix build`, delete any `result` symlink.
- A graph with no cgo package must produce the same derivation shapes as before: bare `derivation` for every compile and link, and unchanged emitted Nix text.
- Not supported, and rejected by `resolve` with a message naming the package and the kind of file: SWIG, Fortran, `.syso`.
- cmd/go's `#cgo` flag allowlist is not ported.
- Work happens on branch `cgo`. Every commit message ends with:

1. **A `package main` that itself imports `"C"`.** It must compile with `-p main` and `cgo -dynpackage main`, and link. Pinned in Task 6 (`TestCgoMainPackage`).

Pinned in Task 2 (`TestNixCgoRoundTripsThroughNix`) and Task 5 (`TestRunCgo` defines such a macro and the program prints it).

5. **A package that needs pkg-config when there is none.** The error must name the pkg-config packages and the `packageOverrides` attributes to set. Pinned in Task 5 (`TestRunCgoPkgConfigMissing`).

`cgo.go`:

```go
package graph

import "strings"

const srcDirVar = "${SRCDIR}"

// restoreSrcDir undoes go list's expansion of ${SRCDIR} in a package's
// #cgo flags. go list substitutes the directory it found the package in,
// which is the module cache's or the evaluation-time source's; the package
// is built somewhere else.
func restoreSrcDir(flags []string, dir string) []string {
	if len(flags) == 0 {
		return nil
	}
	out := make([]string, len(flags))
	for i, flag := range flags {
		out[i] = strings.ReplaceAll(flag, dir, srcDirVar)
	}
	return out
}

// srcDirRefs returns what follows each ${SRCDIR} in flags, up to the
// character that ends a path inside a flag.
func srcDirRefs(flags []string) []string {
	var refs []string
	for _, flag := range flags {
		for {
			i := strings.Index(flag, srcDirVar)
			if i < 0 {
				break
			}
			flag = flag[i+len(srcDirVar):]
			end := strings.IndexAny(flag, ",=:\"' \t")
			if end < 0 {
				end = len(flag)
			}
			refs = append(refs, flag[:end])
		}
	}
	return refs
}
```

```go
// Package cc drives a C or C++ compiler the way cmd/go does for the C
// side of a cgo package.
package cc

// Target is what the compiler flags depend on.
type Target struct {
	GOOS, GOARCH    string
	GOMIPS, GOMIPS64 string
}

// Compiler is one compiler command aimed at one target.
type Compiler struct { /* unexported */ }

// New prepares the compiler whose command line starts with cmd (from $CC
// or $CXX, already split). env is the environment of every run; cflags
// and ldflags are $CGO_CFLAGS and $CGO_LDFLAGS, which the flag probes
// pass along as cmd/go does. probeDir is a scratch directory.
func New(cmd []string, t Target, env []string, cflags, ldflags []string, probeDir string) *Compiler

// Supports reports whether the compiler accepts flag. Results are cached.
func (c *Compiler) Supports(flag string) bool

// Prefix is how cmd/go starts every command for a package: the compiler,
// -I incDir, and the flags that do not depend on the file (spec step 2,
// up to and including -fno-common). workDir is rewritten to /tmp/go-build.
func (c *Compiler) Prefix(incDir, workDir string) []string

// Job is one compile.
type Job struct {
	Dir    string   // working directory
	IncDir string   // -I value: "." for a file in Dir, else the package directory
	Flags  []string // preprocessor flags then compiler flags
	File   string   // source, relative to Dir
	Obj    string   // output object
	Seed   string   // -frandom-seed value
}

// Compile runs one job. srcMap is the "from=to" of the source root, ""
// for none. The compiler's output goes to stderr.
func (c *Compiler) Compile(j Job, workDir, srcMap string) error

// Link links objs into out with ldflags and returns the compiler's
// output. The caller decides whether a failure matters.
func (c *Compiler) Link(dir, incDir, workDir, out string, objs, ldflags []string) ([]byte, error)

// ArchArgs returns the flags that select the target architecture.
func ArchArgs(t Target) []string

// PkgConfig runs $PKG_CONFIG (default pkg-config), found on the PATH of
// env, for the arguments of a package's #cgo pkg-config directives, and
// returns the compiler and the linker flags.
func PkgConfig(env []string, dir string, args []string) (cflags, ldflags []string, err error)

// SplitPkgConfigOutput splits pkg-config's output into flags as a POSIX
// shell would split it into words.
func SplitPkgConfigOutput(out []byte) ([]string, error)
```
